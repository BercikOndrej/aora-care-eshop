# Problem

- I need create small e-shop for my cosmetic products. It should contains about 16 products. Products are part of lines and there will be 3 or 4 lines. Website design should look luxury, natural and earthy. Whole app (FE, BE, DB) should run on VPS. I want to as simple solution as possible. I have choose tech-stack already. I need also handle some logistic of my products (best option is integration of Packeta (Zásilkovna) somehow) and I also need manage warehouse with admin website site.

# Solution

- Small full stack web application that shows my products, handle logistic and implement admin sites witch could edit/update items or its count

# List of Features

- Landing page
- List of products
- Detail page of each product
- Admin page
  - to manage products (adding new product will be handed programmically with DB migration)
  - To update products like description, price, count and so on
- Register sold items to sending service 'Packeta'
- Cart
- Sending emails to confirm order and other info
- Filtering by category/product lines
- Searching product by name
